# Changelog

## 0.3.0

- Open a book as a table (*Open With… → 4PM Book*, or the *Books* view): filter, sort, edit cells and save — the
  changes go to your project's worker, like on the web.
- Add a request to USER_TODO, and approve or unapprove several rows at once.
- *Task board*: tasks waiting for approval, approved, in progress and done.
- Approving a task now also runs its catalog actions, as on the web.

## 0.2.0

- A book row of your linked project opens as a readable card: its details, approval progress and discussions.
- Approve or unapprove a row, and answer a question, from the card.
- See what changed in a row since it was approved (compared with your last commit).
- Start or pause autonomous for the project from the status bar.
- *Discussions* view: read and reply to your project's discussions, open new ones from a row; mentions open the
  discussion.

## 0.1.0

- Sign in through the browser (password, two-factor, SSO) and sign out; the account shows in the Accounts menu.
- Link a workspace to a 4PM project; the status bar shows its worker and autonomous state.
- *My work* view: what waits on you, opening book rows in the editor.
- *Notifications* view with live updates and an unread badge.
- Run a console command or an AI prompt on the project's worker, with the output streamed and a Stop button.
